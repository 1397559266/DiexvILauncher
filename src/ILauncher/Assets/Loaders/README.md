# Loader icons

These are the official project marks, used only to identify the corresponding
Minecraft mod loader. They are trademarks of their respective projects:

| File | Source |
| --- | --- |
| `fabric.png` | https://fabricmc.net/assets/logo.png |
| `quilt.png` | https://github.com/QuiltMC/quiltmc.org/blob/main/public/assets/img/logo-square.png |
| `forge.png` | https://github.com/MinecraftForge/MinecraftForge/blob/26.3/icon.ico |
| `neoforge.png` | Cropped from the official high-resolution face in https://github.com/neoforged/.github/blob/main/art/neoforged_logo.png |
| `optifine.png` | https://optifine.net/favicon.ico |

The icons were resized to 64×64 with nearest-neighbour (or Lanczos for the
Quilt mark) and transparent padding. See the upstream projects for their
trademark and redistribution terms.
